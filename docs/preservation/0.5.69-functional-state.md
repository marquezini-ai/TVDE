## Google Service Account

A integração Google Sheets depende atualmente de uma conta de serviço configurada localmente por `googleServiceAccountJsonPath` em `local.properties`.

O build adiciona o diretório que contém esse JSON ao conjunto principal de assets. Consequentemente, o JSON da conta de serviço é incluído nos APKs de Cliente e Admin. A aplicação usa esse asset para obter tokens OAuth e executar upload e download no Google Sheets.

Os APKs existentes e o JSON da conta de serviço não fazem parte deste estado versionado. A credencial deve ser removida do cliente por uma solução arquitetural própria antes de uma nova distribuição segura.
